# 2027 applications

One subfolder per job application. Each tailored CV is generated from
`../cv_master.tex` using the `tailor-cv` skill.

Suggested naming:

```
2027/
  company-role/
    cv.tex          # tailored source
    cv.pdf          # built output (ATS-safe)
    job-offer.txt   # the pasted job description used for tailoring
    keywords.md     # extracted ATS keywords + coverage notes
```
